# ⚡ SyntaxHub

> **SyntaxHub** is a clean, modern, high-performance developer cheatsheet hub designed to provide instant access to core syntax, programming fundamentals, and essential code snippets across multiple languages.

Built with an ultra-clean, eye-comfort dark theme, real-time search, interactive language filters, and offline capability.

---

## ✨ Key Features

- 📚 **Comprehensive Language Coverage:** Includes core fundamentals (Variables, Control Flow, Loops, Functions) and advanced snippets for **C#**, **C++**, **JavaScript**, **TypeScript**, **Python**, **Java**, **PHP**, **SQL**, and **HTML/CSS**.
- ⚡ **Instant Fuzzy Search:** Filter syntax and code snippets in real-time as you type.
- 🎨 **Minimalist Developer Theme:** Eye-comfort dark mode slate palette with code highlighting.
- 📋 **One-Click Code Copy:** Easily copy code blocks to clipboard with dynamic toast feedback.
- ⭐ **Favorites System:** Save your most-used snippets locally via browser `localStorage`.
- 📁 **Download Snippets:** Export code directly into appropriate file extensions (`.cs`, `.cpp`, `.js`, etc.).
- 🌐 **Bilingual Support (AR / EN):** Seamlessly toggle layout direction (`RTL`/`LTR`) while retaining code formatting.
- 📴 **PWA & Offline Ready:** Fully accessible offline with instant load times.

---

## 🛠️ Tech Stack

- **Frontend:** Vanilla HTML5, CSS3 (Custom Variables, Flexbox/Grid), JavaScript (ES6+)
- **Data Source:** External JSON-driven architecture (`data/snippets.json`)
- **Storage:** Browser `localStorage` for user preferences and custom snippets
